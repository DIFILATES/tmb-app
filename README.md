# TMB Objectes Perduts 🚇

Aplicació web per gestionar objectes perduts i trobats al transport públic de Barcelona (TMB).

## Funcionalitats

- 📦 **Registrar objectes trobats** — Formulari per a usuaris que troben objectes
- 🔎 **Registrar objectes perduts** — Formulari per a usuaris que han perdut objectes
- 🤝 **Seguiment de matches** — Sistema de coincidències (pendent, confirmat, tancat)
- 📱 **Disseny mobile-first** — Optimitzat per a ús amb mòbil, amb navegació inferior
- 🔄 **Dades en temps real** — Sincronització via Firebase Realtime Database

## Tecnologies

- HTML5, CSS3, JavaScript (Vanilla)
- Firebase Realtime Database
- GitHub Pages (allotjament)

## Desplegament

L'aplicació està disponible públicament via GitHub Pages.
